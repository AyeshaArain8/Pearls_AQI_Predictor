# Pearls Lahore AQI Predictor

An end-to-end, Lahore-only 3-day AQI forecasting project. It uses OpenWeather observations, a free local file-based Feature Store, versioned local model registry, scikit-learn Random Forest models, Streamlit, SHAP, and GitHub Actions.

## Architecture

`OpenWeather -> src/feature_pipeline.py -> data/feature_store/lahore_observations.csv -> shared feature contract -> training/registry and live inference -> Streamlit`

The Feature Store is a local CSV plus `schema.json`; it is free and stores chronological observed Lahore AQI and six pollutant readings. New records are collected for Lahore from OpenWeather. It is deliberately not Supabase, Hopsworks, or Vertex AI. A new store begins with verified live observations and needs at least three prior observations before it can forecast.

## Canonical features and data sources

The production schema is defined once in `src/feature_contract.py`: `pm10`, `pm2_5`, `carbon_monoxide`, `nitrogen_dioxide`, `sulphur_dioxide`, `ozone`, calendar fields, and AQI lag 1-3 plus a three-observation rolling mean. Pollutants are available from both historical data and OpenWeather. AOD, dust, UV, city encodings, and hardcoded values were removed because they cannot be truthfully generated by the live API.

For a live record, AQI is deterministically derived from its observed PM2.5 via documented EPA breakpoints. Lags and rolling features always come from three actual preceding Feature Store observations. If history is insufficient, the application fails safely - it never makes up values.

## Training and registry

Run `python src/train_forecast.py`. It creates features using the same shared function as serving, uses an 80/20 chronological split, trains day 1/day 2/day 3 models, and records RMSE, MAE, R2, feature schema/version, training date, and data range under `models/registry/<version>/`. `models/registry/latest.json` is the approved model pointer loaded by inference.

### Historical dataset provenance gate

`data/historical/air_quality_historical.csv` has no city, coordinate, source URL, or provenance field, and the repository contains no evidence proving that it is Lahore data. It is therefore **not approved for Lahore training**. `data/historical/metadata.json` records this as unverified and historical Feature Store initialization refuses to proceed. The training pipeline only accepts a Feature Store whose metadata identifies either verified Lahore historical data or Lahore OpenWeather live observations. Before enabling a historical backfill, obtain the original source evidence and set `geographic_scope` to `Lahore, Pakistan`, `lahore_verified` to `true`, and `provenance` to an auditable source URL/reference. Do not bypass this control merely to make the pipeline run.

## Local setup

```bash
python -m pip install -r requirements.txt
set OPENWEATHER_API_KEY=your_key
python src/feature_pipeline.py
python src/train_forecast.py
streamlit run app.py
pytest -q
```

The API key belongs in `.env` locally and `OPENWEATHER_API_KEY` GitHub Secret in Actions. It is never committed. The hourly workflow runs at `0 * * * *`; the daily training workflow runs at `0 0 * * *`. Both provide `workflow_dispatch`. The workflows commit Feature Store updates and approved Model Registry versions back to the repository, which is how separate GitHub runners share this intentionally file-based implementation.

## Dashboard and explainability

The Streamlit dashboard has no city selector: it forecasts Lahore only, reports OpenWeather source/current pollutants, displays dated three-day forecasts, model metrics, and an alert when any forecast is Hazardous (>300). If the optional SHAP dependency works, it shows a local explanation of tomorrow's actual registered model. If SHAP cannot run, forecasting remains available.

## Tests and limitations

`pytest -q` tests canonical schema/train-serve parity, real lag and rolling calculations, insufficient-history handling, Lahore configuration, and three-day prediction shape. Live collection requires OpenWeather availability and a valid key. Historical training is deliberately blocked until its Lahore provenance is verified.
